
# Contributing to PREDIX

Thank you for contributing to PREDIX.

PREDIX is being developed as a team project for Smart India Hackathon 2026.

---

# 1. Branch Policy

## `main` is the protected integration branch.

Only the **Team Lead / Repository Owner** may merge changes into `main`.

### DO NOT:

- Push directly to `main`
- Commit directly to `main`
- Force push to `main`
- Merge your own Pull Request
- Rewrite `main` history

All contributors must work on their own feature branch.

---

# 2. Branch Naming

Each contributor should create a dedicated branch for their assigned module.

Recommended branches:

```text
feature/data-pipeline
feature/cost-model
feature/time-model
feature/risk-engine
feature/analytics
feature/dashboard
